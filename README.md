## crossword

### Description

Crossword is able to solve an empty crossword puzzle.

The function takes two arguments:

- an empty puzzle, passed as a string
- a list of words to fill in the puzzle (no double words allowed)

### Usage

Manage your puzzles and word lists in the test_file.js file like this:

```js
puzzles.push('2001\n0..0\n1000\n0..0')
words.push(['casa', 'alan', 'ciao', 'anta'])
```

To run:

```bash
$ node main.js
```
